# 小程序产品说明

## 产品定位

小程序只做 AI 文生图。目标用户是需要快速把想法、商品、场景或海报概念变成图片的人，打开后直接输入提示词、生成图片、查看结果、复用历史。

## 本期目标

- 首页只保留文生图输入和生成结果。
- 支持提示词优化，但不强迫用户先优化。
- 常用设置只有风格、尺寸、质量和负面提示词。
- 生成后展示大图、状态、最终提示词和可复制图片链接。
- 历史任务支持点按复用提示词，失败任务支持重试。
- 小程序始终请求线上域名 `https://api2.hometodo.top/wximg`。

## 体验原则

- 少入口：不再展示头条图文、发布稿、需求流、测试验收等内容。
- 少字段：默认设置要足够好，更多设置收起。
- 强结果：结果区先看图片，再看提示词。
- 可复用：历史不是记录墙，而是下一次生成的快捷入口。
- 可恢复：失败任务保留原因和重试入口。

## 技术方案

- `POST /api/generations` 创建图片任务。
- `GET /api/generations/{job_id}` 轮询任务状态。
- `POST /api/generations/{job_id}/retry` 重试失败或历史任务。
- `POST /api/prompt-optimize` 优化提示词。
- 图片生成仍使用后端异步队列，结果落盘到服务器并通过 `/api/images/{filename}` 访问。
- 后端不再暴露旧的图文发布和流程看板接口，避免产品边界回流。

## 测试验收

- `pytest -q`
- `python -m compileall app`
- `node -c miniprogram/pages/index/index.js`
- 微信开发者工具打开项目并检查：
  - 首屏只有文生图。
  - 示例提示词可填入。
  - 优化提示词可复制和使用。
  - 生成任务能进入轮询。
  - 图片成功后可预览并复制链接。
  - 最近任务可复用，失败任务可重试。
