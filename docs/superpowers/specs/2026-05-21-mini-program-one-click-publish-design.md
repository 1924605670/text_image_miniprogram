# 小程序一键发布稿重构设计

## 背景

当前小程序已经是“头条图文创作台”，能基于选题、事实材料、角度、读者和样式设置生成标题、导语、正文、要点、合规检查和封面任务。现有体验的问题是首屏表单项偏多，生成后的操作按钮分散，默认复制内容包含封面提示词等内部信息，不够贴合运营/编辑的日常发文流程。

本次重构聚焦运营/编辑日常发文场景，目标是让用户更快完成“输入事实材料 → 一键生成 → 复制可发布正文”。

## 产品目标

- 首页保持工作台形态，不增加营销页或多页面导航。
- 首屏输入降低到三项：选题、事实材料、生成设置。
- 角度、目标读者、文章类型、篇幅、封面风格和是否生成封面图放入高级设置。
- 主按钮从“生成头条图文”调整为“生成发布稿”。
- 生成成功后页面重心转向结果区，突出“复制发布稿”。
- “复制发布稿”只复制标题、导语和正文，不复制合规检查、待核提醒或封面提示词。
- 保留分块复制能力，方便编辑单独复制标题或正文。
- 合规、待核、封面策划和最近封面任务作为辅助信息展示。

## 用户流程

1. 用户打开首页，看到服务状态、输入卡片和“生成发布稿”按钮。
2. 用户填写选题和事实材料。
3. 用户可直接使用默认生成设置，也可展开高级设置调整角度、读者、类型、篇幅、封面风格和封面开关。
4. 用户点击“生成发布稿”。
5. 小程序校验选题和事实材料，调用现有 `/api/toutiao-packages`。
6. 文案生成成功后展示发布预览，并将主操作切换为“复制发布稿”。
7. 如果启用封面图，小程序继续轮询图片任务状态并展示封面预览。
8. 用户复制发布稿后，可查看备选标题、要点、合规与复核提醒，必要时再分块复制。

## 信息架构

页面从上到下分为五个区域：

1. 顶部状态区
   - 产品名称：头条图文创作台。
   - 简短说明：事实材料生成可发布草稿。
   - 服务状态胶囊：服务器已连接、服务器待配置或连接失败。

2. 输入区
   - 选题输入。
   - 事实材料大文本框。
   - 示例按钮。
   - 生成设置摘要 chips，例如“资讯快讯”“标准”“生成封面”。
   - 高级设置折叠面板。
   - 主按钮“生成发布稿”。
   - 表单错误提示。

3. 结果区
   - 成功状态文案。
   - 主按钮“复制发布稿”。
   - 次级按钮“复制标题”“复制正文”。
   - 发布预览：推荐标题、导语、正文段落。

4. 辅助区
   - 备选标题。
   - 要点摘要。
   - 封面策划、图片 prompt、负面 prompt。
   - 封面图任务状态和封面预览。
   - 合规检查和事实复核提醒。

5. 历史区
   - 最近封面任务。
   - 刷新入口。
   - 历史区保持低视觉权重，避免干扰当前发布稿。

## UI 设计

整体继续使用浅色工具风格，但强化编辑效率：

- 顶部 hero 缩小高度，状态胶囊放右侧或标题下方。
- 输入卡片使用更强的主次层级，事实材料文本框是视觉中心。
- 生成设置使用 chips 展示当前选项，默认不展开高级表单。
- 高级设置采用折叠面板，展开后复用现有 picker 和 switch。
- 主按钮使用高饱和色，按钮文案为“生成发布稿”。
- 结果卡片改为发布预览样式，标题字号最大，导语和正文按阅读层级排列。
- “复制发布稿”使用结果区最强按钮样式。
- 合规与待核提醒使用弱提示或警示色，不混入发布预览。
- 封面任务状态文案清晰区分“排队中”“生成中”“已完成”“失败”。

## 开发方案

本次不修改后端接口，继续使用现有数据结构和 API：

- `GET /api/health`：服务状态。
- `POST /api/toutiao-packages`：生成图文内容包。
- `GET /api/generations/{job_id}`：轮询封面图任务。
- `GET /api/generations?limit=8`：最近封面任务。

小程序前端重构集中在 `miniprogram/pages/index/`：

- `index.js`
  - 增加 `advancedOpen` 控制高级设置展开。
  - 增加 `settingSummary` 或等价派生字段展示 chips。
  - 增加 `publishDraft`，由生成结果格式化得到。
  - 调整复制逻辑：`copyPublishDraft` 复制标题、导语、正文；`copyTitle` 和 `copyBody` 保留分块复制。
  - 生成成功后更新结果状态，并尽量将页面滚动到结果区。
  - 保留现有健康检查、示例、请求封装、图片任务轮询和历史加载。

- `index.wxml`
  - 按顶部状态区、输入区、结果区、辅助区、历史区重组结构。
  - 将高级设置包在可展开区域内。
  - 将结果区主按钮调整为“复制发布稿”。
  - 将合规、复核、封面和历史从主要发布预览中拆出。

- `index.wxss`
  - 重做 hero、panel、chips、折叠设置、结果预览、按钮层级和辅助模块样式。
  - 保持当前色系基础，增强主操作与辅助信息的视觉区分。

## 数据与状态

页面状态分为五类：

- 输入状态：`topic`、`facts`。
- 设置状态：`angle`、`audience`、`articleStyleIndex`、`lengthIndex`、`coverStyleIndex`、`includeImage`、`advancedOpen`。
- 生成状态：`creating`、`error`、`result`、`bodyParagraphs`、`publishDraft`。
- 图片任务状态：`imageJob`、`imageUrl`、`jobStatusText`。
- 历史状态：`recentJobs`。

发布稿格式固定为：

```text
{best_title}

{lead}

{body}
```

如果某个字段为空，则跳过空段，避免复制出多余空白。

## 错误处理

- 选题少于 2 个字时，提示用户填写选题。
- 事实材料少于 10 个字时，提示用户填写可核验事实。
- 文案生成请求失败时，在输入区下方展示错误原因。
- 图片生成失败时，只在封面辅助区展示失败原因，不影响发布稿复制。
- 健康检查失败时顶部状态显示“服务器连接失败”，但不阻止用户尝试生成。

## 测试与验收

开发完成后需要验证：

- `node -c miniprogram/pages/index/index.js` 通过。
- 默认首屏只展示选题、事实材料、生成设置摘要和主按钮。
- 高级设置可展开并能正确修改角度、读者、类型、篇幅、封面风格和封面开关。
- 示例按钮能填充可生成内容。
- 生成成功后展示结果区，主操作为“复制发布稿”。
- “复制发布稿”只包含标题、导语和正文。
- “复制标题”和“复制正文”可单独工作。
- 勾选封面图时能展示任务状态，并在成功后展示预览。
- 最近封面任务仍可加载和刷新。

## 非目标

- 不新增后端接口。
- 不引入登录、额度、模板库或多页面历史管理。
- 不改变 LLM prompt 或生成 schema。
- 不实现真实小程序测试版上传链路。
